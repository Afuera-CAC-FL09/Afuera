# Parent consent for filming (draft)

Draft for Non-tech A. Before sending, have the school or program check it against their own media release rules; many districts require their own form, and theirs wins. Print both languages on one sheet. Due back **Friday, October 17**.

Fill in the brackets. Keep signed forms private; don't put them in this repo (`docs/` is public). Only list kids by first initial in any notes here.
